# Formation pratique — entraînement et post-training des LLM

Ce dossier contient **62 modules pédagogique**, du fonctionnement d’un LLM jusqu’au pré-entraînement from scratch, LoRA/QLoRA, full fine-tuning, DPO, reward modeling, RL, GRPO/PPO, FSDP et aux projets de synthèse.

## Philosophie

Le cours privilégie :

```text
définition concrète
→ intuition simple
→ exemple minimal
→ fonctionnement réel
→ maths utiles
→ code observable
→ laboratoire
→ validation
```

Les exemples d’utilisation ne remplacent jamais l’explication du mécanisme.

## Commencer ici

1. Lis [00_METHODE_ET_ENVIRONNEMENT.md](00_METHODE_ET_ENVIRONNEMENT.md).
2. Ouvre [INDEX.md](INDEX.md).
3. Commence par le module 1.
4. Ne passe au suivant qu’après sa section **Validation**.
